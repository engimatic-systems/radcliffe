# Radcliffe foundation: reliable voice, provenance, and safe agent tools

Establish the production foundations required before feature expansion: reproducible delivery, Protocol v2, mobile WebRTC connectivity, explicit session semantics, source provenance, and a safe structured-tool path.

## Acceptance Criteria

The epic is complete when all child tickets are closed; the spec is implemented enough to support an end-to-end Android-to-agent session; all required conformance, security, and device gates pass; and the system is ready for deterministic source reading and safe tool expansion.
